## 운영진 안내 (채용공고 데이터)

- 고용24 Open API는 예시로 제시된 소스이며 필수가 아닙니다. 공공데이터포털 오픈 API나 샘플 데이터셋 등 다른 데이터를 써도 됩니다.
- 어떤 데이터 소스를 썼는지에 따른 가점이나 감점은 없습니다.
- 결과물과 발표 자료에 출처, 수집 범위, 한계를 명확히 적어야 합니다.

## 2026-11-12 결정

- 공공기관·공기업 채용 데이터는 쓰지 않습니다. 직무를 정보통신으로 묶어 뽑아 직무별 요구 기술을 구분할 수 없습니다. 보조로 두었던 공공데이터포털 채용 API 3개는 수집 대상에서 뺍니다.
- 로켓펀치 API는 `keyword` 검색이 제목과 한 줄 소개에만 걸립니다. 넓게 받아온 뒤 본문·자격 요건 필드에서 키워드로 거릅니다. 이 방식과 걸러진 건수를 한계에 적습니다.
- 경력 조건이 붙은 공고가 대부분입니다. 경력 연차는 분석에 쓰지 않으며 이 점을 한계에 적습니다.
- AWS 교육과정은 SkillBuilder 목록을 스크립트로 받아 관련 과정만 선별합니다. 수집일, 전체 건수, 선별 기준, 이용약관 확인 결과를 표에 적습니다.
- S3에는 API 응답 JSON을 저장하고 공고 웹페이지 원문 전체는 저장하지 않습니다.

수동으로 모은 공고는 한 건마다 출처 주소와 수집일을 남기고, 원문은 `data/raw/`에만 두어 저장소에 올리지 않습니다.

## AWS 교육과정 이용 조건 (2026-11-13 확인)

- AWS 사이트 약관(2025-06-04 개정)은 사이트 이용을 개인적 용도로 한정하고 자동 수집 도구 사용을 제한합니다. Skill Builder 전용 약관은 찾지 못했습니다.
- 대회 측에 확인해 교육·대회 목적 사용은 가능하다는 답을 받고 수집했습니다(2026-11-13).
- 원문(`data/raw/courses/`)은 저장소와 공개 저장소에 올리지 않습니다. 전처리한 표(`data/courses/`)는 비공개 저장소에만 두고 공개 동기화 대상에 넣지 않습니다.
- 화면에는 과정 제목, 학습 목표 한 문장, 원본 링크만 보여주고 상세는 Skill Builder로 보내는 안을 제안합니다(회의 확정 대기).
