# 개선 기록 (ai/)

발표와 회고에 쓰는 개선 기록이다. 항목마다 **문제를 무엇으로 알았는지, 무엇을 바꿨는지, 숫자가 어떻게 바뀌었는지, 그 숫자를 어떤 조건에서 쟀는지**를 적는다.

- 숫자는 PR 설명과 결과 파일(`outputs/eval/`, 커밋하지 않음)에 있는 값만 쓴다. 근거가 없으면 "확인 필요"로 둔다.
- 공고 원문, 회사명, 공고 번호는 적지 않는다(`ai/`는 공개 폴더).
- 팀원 작업 덕분인 개선은 **[누구 작업]** 으로 표시한다.
- 모델: 추출·추천·상담은 `global.anthropic.claude-sonnet-4-6`(temperature 0), 임베딩은 `amazon.titan-embed-text-v2:0`.
- 데이터 이름
  - **가짜 10건**: `data/sample/postings.json` 과 정답지 `ai/eval/gold_extraction.json`. 프롬프트를 고칠 때 본 개선용 데이터라 점수는 과대평가다.
  - **dev 12건**: 외부 채용 플랫폼 실제 공고 12건(커밋하지 않음). 정답이 없는 개선용 데이터.
  - **DynamoDB 12건**: 팀 DynamoDB 수요 집계(실제 공고 12건). 화면과 상담 에이전트가 읽는다.
  - **채점용 공고**: 고칠 때 보지 않은 실제 공고 10건(#21). 아직 채점 전.
